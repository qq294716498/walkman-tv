# 个性化音乐实施记录

本分支保留现有顶部导航、左侧正在播放区域和推荐歌单、排行榜。

## 已接入

- 推荐页显示账号入口、每日推荐、私人 FM、心动模式、猜你喜欢和云端歌单。
- 网易云音乐、QQ 音乐分别支持扫码添加多个账号、切换当前账号和移除当前账号。登录凭据通过 Android Keystore 加密后保存在设备上，不写入仓库。
- 个性化入口向当前选中的平台账号请求数据。QQ 音乐的“每日推荐”使用雷达推荐，“私人 FM”使用电台推荐，“心动模式”展示账号“我喜欢”的歌曲。
- 云端歌单可查看详情并进入现有播放列表。语音搜索接入当前多平台搜索流程；没有系统语音识别服务时显示提示。
- 共用 TV 焦点控件和顶部导航已支持点击触摸，仍保留遥控器操作。

## 验证边界

- GitHub Actions 的 Debug Build 检查 Kotlin 编译并输出测试 APK。
- 网易云和 QQ 的账号授权及个性化接口会随平台协议变化，实际扫码登录、私有歌单和播放结果需要在用户设备上验证。
- 仅在独立开发分支工作，不合并 main。
